## Deployment Method
This repository must be deployed using **GitHub Pages branch-based deployment** only:
- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/root**

## Deployment Warning
⚠️ **Do not use GitHub Actions deployment for this repository.**

- Do not create `.github/workflows`.
- Do not use `actions/deploy-pages`.
- Do not add any workflow-based deployment pipeline.
